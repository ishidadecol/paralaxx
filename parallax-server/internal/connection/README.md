#Package connection

The connection package is responsible for managing relationships between entities.

Examples:

- John KNOWS Joe
- John WORKS_AT Acme Corp
- Acme Corp LOCATED_IN New York

A connection represents a relationship between a source entity and a target entity.

This package is not related to infrastructure connections such as database connections, network connections, or external service connections.

Note: The package name may be changed in the future if a more specific name better reflects its purpose within the graph model.
